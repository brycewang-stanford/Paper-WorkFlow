# China Data Sources — 中国实证研究数据源手册

> 本文档是 Paper-WorkFlow 的「中国数据源路由总表」。Stage 2 取数时按本表选择数据源、申请
> 方式、字段映射、清洗陷阱；Stage 3-5 引用中国数据时按本文规范写 `data_governance.md`、
> `codebook.md`、`sample_audit.md`；Stage 9 投稿与收尾时按 §1 数据合规要求披露 DAS。
>
> **本文与现有 references 体系的边界**：数据合规与 DAS 仍以
> [`data-governance.md`](data-governance.md) 为准，本文只补「中国语境」特有部分（个人信息
> 保护法、数据出境安全评估办法、人类遗传资源管理条例）；识别威胁与样本审计仍以
> [`empirical-audit.md`](empirical-audit.md) 为准。

## 0. 快速索引（按研究主题）

| 研究主题 | 首选数据源 | 备选 / 增强 | 关键字段警示 |
|---|---|---|---|
| **公司金融 / 公司治理** | CSMAR + WIND + CNINFO | RESSET、巨潮资讯网 | 行业代码（GB/T 4754 vs 证监会 2012）冲突；ST/\*ST 状态识别 |
| **股价 / 事件研究** | CSMAR 交易数据 + WIND | RESSET、CSMAR 高频 | 复权方式（前/后复权 vs 总股本加权）；停牌日处理 |
| **家庭金融 / 微观调查** | CHFS（西南财大） | CFPS（北大）、CHARLS（北大健康养老） | 抽样权重 / 跨年追踪 ID；资产与负债漏报 |
| **健康 / 养老 / 医学** | CHARLS | CLHLS（老年健康）、中国健康与营养调查（CHNS） | 人类遗传资源合规；样本年龄限制 |
| **劳动 / 就业 / 教育** | UHS（高校毕业生就业）、CGSS（中国综合社会调查） | CEPS（教育追踪）、CFPS 劳动模块 | 城镇/农村分组口径；流动人口识别 |
| **区域经济 / 城市** | 地级市统计年鉴 + CEIC | EPS 数据平台、省级统计公报 | 行政区划代码变更；撤县设区 |
| **政府数据 / 财政** | 国家统计局 + 财政部 + CEIC | 地方财政年鉴、地级市财政预算执行报告 | 决算 vs 预算口径；"一般公共预算"统计口径变化 |
| **产业 / 制造业** | 工业企业数据库（CID） | 上市公司财务数据、行业协会 | 销售额 500 万元门槛；规模以上 vs 全部 |
| **贸易 / 关税** | 海关总署 HS 数据 | UN Comtrade、CEPII BACI | HS 编码版本（1992/1996/2002/2007/2012/2017）；贸易类型（一般/加工） |
| **专利 / 创新** | 国家知识产权局 + incoPat | Patentics、Google Patents | IPC 分类 vs CPC；申请号 vs 公开号 |
| **土地 / 房地产** | 中国土地市场网 + 自然资源部 | CREIS 中指院、CRE 克尔瑞 | 土地用途分类；出让 vs 划拨 |
| **环境 / 污染** | 中国环境统计年鉴 + 排污许可 | 公众环境研究中心（IPE）、AQI 历史数据 | 缺失值多；指标统计口径变化 |
| **政策 / 法律 / 制度** | 北大法宝 + 国务院公报 | 中国法律法规数据库、地方法律法规网 | 法规效力层级；时间版本 |
| **文本 / 媒体 / 舆情** | CNRDS 财经新闻 + Wind 公告 | 百度搜索指数、新浪微博 API | 中文分词；词袋 vs 主题模型 |
| **招投标 / 政府采购** | 中国政府采购网 + 全国公共资源交易平台 | 剑鱼标讯、千里马招标 | 公告 vs 中标；信息缺失 |
| **工商注册 / 企业图谱** | 天眼查 + 启信宝 | 企查查、爱企查 | 高管关联网络；股权穿透 |
| **土地 / 地理 / POI** | 高德开放平台 + 百度地图 | 数据堂、CEIC 城市数据 | API 调用限额；坐标系 (WGS84 vs GCJ-02) |

> **特别提示**：国内数据源**没有统一的 metadata 标准**，每个数据源都有自己的变量名、编码
> 规则、缺失值标记（`-99`、`-98`、`.`、`NULL`、`空白`），跨源合并前必须建一张「字段映射表」。
> 详见 §12 清洗陷阱。

## 1. 中国数据合规与申请框架（先于取数）

### 1.1 法律层级（按重要性递减）

| 法律 / 法规 | 关键条款 | 对实证研究的影响 |
|---|---|---|
| 《个人信息保护法》（PIPL, 2021.11.1） | 个人信息处理须告知同意；含个人金融账户、医疗、行踪属敏感个人信息 | CHARLS、CFPS、CHFS 等微观调查数据**必须脱敏处理**；不可逆识别符必须哈希或删除 |
| 《数据出境安全评估办法》（2022.9.1） | 处理 100 万人个人信息的处理者向境外提供个人信息须申报安全评估 | 中国学者与境外合作者共享含个人信息的微观数据**必须评估**或通过"数据不出境 + 远程访问"模式 |
| 《人类遗传资源管理条例》（2019） | 涉及人类遗传资源的采集、保藏、利用须备案 | 涉及基因数据的合作研究（如 CHARLS 生物样本子库）须走科技部备案 |
| 《统计法》（2010 修订） | 属于国家秘密的统计资料不得公开；个体调查数据原则上 5 年保密期 | 工业企业数据库等微观数据**仅在科研立项后**可申请使用 |
| 《网络安全法》《数据安全法》（2021） | 数据分类分级；重要数据出境安全评估 | 涉及关键基础设施、金融、能源等"重要数据"的研究须评估 |

### 1.2 数据分级实操

| 分级 | 中国语境典型数据 | 公共复现包处理 | gate 状态 |
|---|---|---|---|
| **公开 (public)** | 上市公司年报、CSMAR 部分字段、统计公报、年鉴 PDF | 可纳入；记录 URL + 版本 + 访问日期 + 引用 | 无限制 |
| **受限 (restricted)** | CSMAR 完整版、WIND 终端、CHARLS/CFPS/CHFS 微观个体数据、企业专利明细 | **不放原始数据**；放获取流程、变量字典、清洗脚本、合成样例、DAS | `method_gate` 需有合法访问说明 |
| **保密 (confidential)** | 工业企业数据库 CID（年度补充调查）、海关总署逐笔交易数据、央行反洗钱数据 | 只放代码 + 远程访问说明；`replication_pack.status = not_ready` | `method_gate.status = not_pass` |
| **PII / 敏感个人信息** | 微观调查中的身份证号、姓名、电话、详细住址、医疗记录、基因数据 | **必须哈希或脱敏**；个体级别数据原则上**不可公开** | 任何公开披露违规 = 自动 `quality_gate = fail` |

### 1.3 学术研究的数据申请三大原则

1. **来源合法**：数据来源须有授权链（学校订阅、国家统计局公开、IRB 审批通过的数据使用申请），不得使用未经授权的爬取/泄露数据。
2. **使用范围匹配**：多数中国数据源的服务条款都规定"仅用于学术研究、非商业用途、不得二次分发"。
3. **DAS 必须诚实**：复现包中 DAS（Data Availability Statement）须区分三类：
   - **可公开**：原始数据可下载（写 URL）。
   - **受限但可申请**：列申请流程、时间、费用。
   - **不可复现**：列出具体原因（如保密、协议限制、不可分发）。

### 1.4 数据出境实操要点（2024-2026 最新）

- 100 万人以上个人信息处理者**向境外提供个人信息**前必须申报数据出境安全评估。
- **WTO 通行做法**：使用国内镜像站（如 CSMAR 境内版）、境外合作者通过"远程访问 + 计算结果回传"模式。
- 与海外合作者共享中国微观数据时，**应优先采用"数据不出境 + 联合分析"模式**，而非整库传输。

## 2. 上市公司与金融市场数据

### 2.1 CSMAR（国泰安，深圳希施玛）

- **官网**：https://data.csmar.com/
- **运营**：深圳希施玛数据科技有限公司
- **覆盖**：A 股、港股、新三板、债券、基金、外汇、商品
- **核心模块**（按研究主题分类）：

| 模块 | 关键字段 | 典型论文 |
|---|---|---|
| 公司研究系列 | 财务分析指标、资产负债表、利润表、现金流量表；股权结构、高管薪酬、关联交易 | 公司治理、薪酬激励、盈余管理 |
| 股票交易系列 | 日/周/月 K 线、复权因子、换手率、流通市值 | 事件研究、动量/反转 |
| 治理结构 | 董事会、监事会、独董人数、高管背景 | 治理与企业行为 |
| 关联交易 | 关联方、交易金额、定价方式 | 关联交易、隧道效应 |
| 分析师预测 | 分析师 ID、评级、目标价、预测偏差 | 信息披露、分析师关注 |
| 投资者情绪 | 情感打分、文本情绪指数 | 行为金融 |
| 创新专利 | 申请号、IPC 分类、引用、被引 | 创新与企业价值 |
| 绿色金融 | ESG 评分、绿色债券 | ESG、绿色金融 |

- **字段命名规则**：以「表名_字段名」形式，如 `Stkrd_capchg` 表示股本变动。
- **缺失值标记**：`.`、`NULL`、空字符串、`-999` 等。
- **学术访问**：多数 985/211 院校已购买 CSMAR 校园 IP 权限；校外需单独购买（约 5,000-30,000 元/年）。
- **下载方式**：网页批量下载、CSMAR API（需付费）、Python `csmarapi` 第三方库、Stata `cntrade` 第三方包。
- **注意事项**：
  - 行业代码：CSMAR 默认用**证监会 2012 行业分类**（C 制造业大类 13-43），但部分字段保留**GB/T 4754 国民经济行业分类**。合并前必须确认。
  - ST/\*ST 标记：财务异常状态会影响样本选择，建议单独建 `ST` 哑变量用于稳健性检验。
  - 财务数据调整：注意"是否调整"、"调整方式"（追溯调整 vs 当期）。
  - 关联交易金额单位：部分字段是元，部分是万元。

### 2.2 WIND（万得）

- **官网**：https://www.wind.com.cn/
- **覆盖**：A 股、港股、美股、债券、期货、外汇、基金、宏观行业、专题统计
- **特色模块**：
  - ESG 评级、Wind ESG 分行业
  - Wind 数据库 - 行业经济数据库（涵盖 30+ 国民经济行业大类）
  - Wind 政策数据库（国务院文件、各部委文件）
  - Wind 资讯（财经新闻、研报）
- **学术访问**：学校订阅通常含 WIND 终端；WIND API 需付费；Python 接入 `WindPy`、R 接入 `windR`。
- **与 CSMAR 的对比**：
  - CSMAR 学术导向强、字段规范、价格便宜。
  - WIND 商业应用广、字段覆盖全（含 ESG、债券、宏观），但字段命名不一致（很多字段是中文名）。
  - **建议**：金融研究用 CSMAR + WIND 交叉验证；产业研究优先 WIND。
- **关键陷阱**：
  - WIND 部分字段缺失值用 "---" 表示，不是 NULL。
  - 数据日期与交易日不匹配（如某日数据更新到上午 9 点）。
  - WIND 终端导出有 100 万行限制；大数据量需分批。

### 2.3 RESSET（锐思数据）

- **官网**：https://www.resset.cn/
- **覆盖**：A 股、港股、债券、基金、宏观行业
- **特色**：清华大学金融研究院背景，部分衍生指标在 CSMAR/WIND 中找不到。
- **学术访问**：学校订阅为主；个别字段需单独付费。
- **使用场景**：CSMAR/WIND 数据验证、补充字段、特殊行业分类。

### 2.4 巨潮资讯网（CNINFO）

- **官网**：http://www.cninfo.com.cn/
- **性质**：深圳证券交易所下属的法定信息披露平台
- **覆盖**：A 股所有上市公司的临时公告、定期报告、招股说明书
- **学术价值**：
  - 上市公司公告全文（PDF/HTML）——文本分析的数据源
  - 管理层讨论与分析（MD&A）——文本挖掘
  - 重大事项公告——事件研究
- **下载方式**：网页手动下载、批量爬虫（注意反爬）、CNINFO 开放 API（已停止）。
- **替代源**：上交所网站（http://www.sse.com.cn/disclosure/），新三板（http://www.neeq.com.cn/）。

### 2.5 股价高频数据

- **CSMAR 高频**：分钟级 OHLCV + 复权因子
- **RESSET 高频**：秒级数据（部分付费）
- **Wind Tick**：逐笔数据（仅商业用户）
- **学术建议**：高频研究大多依赖 CSMAR 高频；微观结构研究需联系学校图书馆争取更高权限。
- **典型清洗**：
  - 复权方式：前复权（保持最新价 = 当前价）、后复权（保持最早期价格）、不复权。
  - 停牌日处理：用前一交易日收盘价或删除。
  - ST/\*ST 标记：研究事件时一般剔除。
  - 异常波动（涨跌停）：保留或删除视研究而定。

### 2.6 债券与基金数据

- **债券**：中国债券信息网 https://www.chinabond.com.cn/、中央国债登记结算公司
- **基金**：Wind 基金、CSMAR 基金、天天基金网
- **典型应用**：利率市场化、信用利差、基金业绩评价

## 3. 微观调查数据（家庭/个人/企业）

### 3.1 CHARLS（中国健康与养老追踪调查）

- **官网**：https://charls.charlsdata.com/
- **主持**：北京大学国家发展研究院
- **覆盖**：45 岁以上中老年人及其配偶；2008 两省试点（甘肃/浙江），2011 全国基线；2013/2015/2018/2020/2023 追访
- **核心模块**：人口学、健康、医疗保险、收入与资产、工作与退休、家庭结构
- **学术访问**：
  - **免费申请**：通过官网注册账号 → 提交研究计划 + IRB 备案 → 等待审批（通常 1-3 个月）
  - 校内下载：部分 985 院校有内部镜像
- **字段命名**：以英文标识符为主（如 `r003` 表示"是否吸烟"）；问卷变量说明见 Codebook。
- **典型应用**：老龄化、健康不平等、医保、家庭代际转移、消费
- **注意事项**：
  - **跨年 ID 匹配**：需用 `ID` + `wave`（如 `rptype`）+ `communityID` 三层键。
  - **抽样权重**：每年权重不同（baseline、interview、respondent 三套权重），必须使用正确权重。
  - **样本年龄**：只在 45 岁及以上，**不能外推到全人口**。
  - **死亡样本**：2020 wave 含部分死亡样本（退出问卷），但生者追溯其死亡信息。

### 3.2 CFPS（中国家庭追踪调查）

- **官网**：https://www.isss.pku.edu.cn/cfps/
- **主持**：北京大学社会科学学部
- **覆盖**：全年龄家庭样本，2010 基线；2012/2014/2016/2018/2020/2022 追访
- **核心模块**：教育、就业、收入、健康、婚姻、家庭、政治态度
- **学术访问**：与 CHARLS 类似（官网申请）
- **典型应用**：教育回报、收入不平等、健康行为、代际流动
- **注意事项**：
  - **基因值缺失**：CFPS 用基因值（用负数如 `-8` 表示不适用、`-9` 表示缺失），必须按 Codebook 处理。
  - **家庭-个人-社区三层结构**：用 `fid10`（家庭 ID）+ `pid`（个人 ID）匹配。
  - **跨年匹配**：每年家庭结构变化（分家、合并、新生、死亡），必须用纵向数据集。

### 3.3 CHFS（中国家庭金融调查）

- **官网**：https://chfs.swufe.edu.cn/
- **主持**：西南财经大学
- **覆盖**：全国家庭，2011 基线；2013/2015/2017/2019/2021/2023 追访
- **特色**：详尽的资产/负债/收入信息（金融资产、住房资产、生产性资产）
- **学术应用**：家庭金融、资产配置、信贷、财富不平等、住房
- **注意事项**：
  - **资产漏报**：高净值家庭资产漏报严重，建议用 Heckman 选择模型或缩尾处理。
  - **房产估值**：自报估值与市场价值偏差大，建议用 Hedonic 模型校准。
  - **抽样权重**：金融模块有专门的金融权重。

### 3.4 CLHLS（中国老年健康影响因素跟踪调查）

- **官网**：https://www.icpsr.umich.edu/web/NACDA/studies/36692
- **主持**：北京大学 + 中国疾控中心
- **覆盖**：65 岁以上老人，1998 基线；多 wave 追访，含死亡样本
- **学术应用**：老年健康、死亡率、医疗服务、长寿
- **特点**：含**死亡代答问卷**，可以做死亡风险研究

### 3.5 CGSS（中国综合社会调查）

- **官网**：http://cgss.ruc.edu.cn/
- **主持**：中国人民大学
- **覆盖**：全年龄综合社会调查，含政治态度、社会信任、文化价值观
- **学术应用**：社会学、政治学、传播学研究
- **特点**：横截面为主（不是面板），不同年份含不同专题模块

### 3.6 CHIP（中国家庭收入项目）

- **主持**：国家统计局 + 北京师范大学
- **覆盖**：1988/1995/2002/2007/2013/2018 多轮
- **特点**：与国家统计局大型住户调查结合，含详细收入和支出信息
- **学术访问**：通过国家统计局或北师大申请

### 3.7 UHS（高校毕业生就业调查）

- **官网**：https://nssd.cn/
- **主持**：北京大学
- **覆盖**：高校应届毕业生，每年一次

### 3.8 RUMiC（城乡移民调查）

- **主持**：牛津大学 + 中国社会科学院
- **覆盖**：流动人口

### 3.9 农村固定观察点

- **官网**：https://www.crreu.cn/
- **主持**：农业农村部农村经济研究中心
- **覆盖**：1986 至今，2 万+ 农户长期跟踪
- **学术应用**：农村经济、土地、劳动力转移

### 3.10 微观调查数据使用通则

1. **IRB / 伦理审查**：使用 CHARLS、CFPS、CHFS 等含人类受试者的微观数据，本校 IRB 必须备案或豁免（多数学校有 IRB 委员会可申请豁免证明）。
2. **数据使用协议（DUA）**：每个微观调查有不同 DUA，下载前必须阅读并签字。
3. **个体级数据不进入公共复现包**：必须脱敏 + 聚合或合成样例。
4. **跨库合并**：CHARLS 与 CFPS、CHFS 不可直接合并（抽样设计不同），可以按地区-时间维度做对比研究。
5. **权重与聚类**：所有微观调查必须使用 `svyset`（Stata）或 `survey` 包（R）指定抽样设计。

## 6. 工业企业数据库（CID）

### 6.1 数据源

- **官方数据**：国家统计局"工业企业统计报表制度"（约 1998-2013 年覆盖较完整）
- **学术获取**：
  - 北京大学中国经济研究中心（CCER）、中央财经大学、对外经贸大学等多个高校已购买多年
  - 通常需要校内专项申请
- **字段**：法人代码、企业名称、行业代码、地区代码、所有制、规模、产值、销售收入、固定资产、职工数等
- **时间跨度**：约 1998-2013 年完整，2014 年后数据质量下降
- **学术应用**：产业组织、企业生产率（OP/LP/ACF/WRDG 方法）、出口与企业行为、政企关系

### 6.2 关键陷阱

- **销售额 500 万元门槛**：1998-2010 为 500 万元，2011 起为 2000 万元，**必须调整**。
- **行业代码**：早期 GB/T 4754-2002，中期 2011，2017 修订；**需用转换表**。
- **缺失值**：早期数据大量缺失营业收入、工业总产值等核心字段；必须用 Heckman 选择模型或缩尾。
- **面板匹配**：法人代码变更（如改制、重组）会导致"消失企业"假象；需用企业名称 + 行业 + 地区联合匹配。
- **会计准则变更**：2007 年新会计准则，导致部分字段定义变化。

### 6.3 学术推荐引用

- Brandt, Loren, Johannes Van Biesebroeck, and Yifan Zhang. "Challenges of working with the Chinese NBS firm-level data." *China Economic Review*, 30 (2014): 339-352 - 系统介绍了 CID 的口径变更、匹配与测量问题及解决方案（引用已核验，见 `_verification_log/cn-data-claims.md` C01）。
- 聂辉华、江艇、杨汝岱："中国工业企业数据库的使用现状和潜在问题"，《世界经济》2012 年第 5 期 - 中文语境下 CID 常见误用与清洗建议。

### 6.4 替代数据源

- **天眼查、启信宝、企查查**：工业企业财务数据连续更新（2013 后），但需付费，且部分字段不一致
- **上市公司财务**：CSMAR/WIND，仅上市公司，覆盖 2013 后
- **启信宝并购数据**：含企业股权变更信息

## 7. 创新与知识产权数据

### 7.1 国家知识产权局

- **官网**：https://www.cnipa.gov.cn/
- **专利检索系统**：https://pss-system.cnipa.gov.cn/
- **商标检索系统**：https://sbj.cnipa.gov.cn/
- **学术数据**：
  - **专利申请数据库**：发明、实用新型、外观设计三种专利类型
  - **地理标志、集成电路布图设计**
- **下载方式**：批量检索需用 API（部分免费）、incoPat（合享智慧谷）、Patentics、北京大学专利数据库等

### 7.2 incoPat（合享智慧谷）

- **官网**：https://www.incopat.com/
- **特色**：专利检索 + 价值评估 + 同族专利，引文数据完整
- **学术访问**：学校订阅，价格较高（10-30 万/年）
- **关键字段**：申请号、公开号、申请日、公开日、IPC/CPC 分类号、申请人、发明人、被引证次数、同族专利数

### 7.3 Patentics

- **官网**：https://www.patentics.com/
- **特色**：与 incoPat 类似，但检索算法不同；学术订阅

### 7.4 学术应用

- 创新指标（专利申请量、授权量、被引数）
- 知识扩散（专利引用、地理扩散）
- 企业创新战略（专利组合、维持时长）

### 7.5 关键陷阱

- **专利质量**：申请量大 ≠ 高质量；用"维持时长"、"被引数"、"权利要求数"衡量。
- **IPC vs CPC**：中国专利用 IPC（国际专利分类）；美国、欧洲同时用 CPC；跨库比较需转换。
- **申请号 vs 公开号**：申请号在申请时分配，公开号在公开时分配；研究时序效应要用**申请日**（更接近实际创新时点）。
- **专利申请人合并**：母公司 + 子公司合并是常见做法，需要手工合并。
- **外观设计与实用新型**：质量较低，多数研究只保留"发明专利"。

| 海关 HS 8 位码 | 3-6 个月 | 需海关总署审批 |
| 中国家庭收入项目 CHIP | 3-6 个月 | 通过北师大或国家统计局 |
| 农村固定观察点 | 1-3 个月 | 通过农业农村部 |

### 11.3 失败回退

| 数据获取失败 | 回退方案 |
|---|---|
| CSMAR 校园无订阅 | 改用 WIND 终端（通常学校有）或 Wind 镜像 |
| CHARLS 申请被拒 | 改用 CFPS（健康模块较少）或 CLHLS |
| CID 数据无法获得 | 改用上市公司财务（CSMAR/WIND，覆盖 2013 后）+ 工商数据（天眼查） |
| 海关 HS 8 位码拒绝 | 改用 HS 6 位码（公开）或 UN Comtrade |
| 统计年鉴缺失 | 用 EPS 数据平台镜像或邻近年份插值 |

## 12. 数据质量与清洗常见陷阱（按发生频率排序）

### 12.1 上市公司财务数据

| 陷阱 | 说明 | 解决方案 |
|---|---|---|
| 行业代码变更 | CSMAR 用证监会 2012 分类，年鉴用 GB/T 4754 | 建 `industry_mapping.csv`，每年单独核查 |
| 财务异常值 | 营业总收入为 0、ROE 超过 100% 等 | 缩尾 (winsorize) 至 1%-99% 分位数 |
| ST/\*ST 标记 | 财务异常公司被特殊处理 | 建 `is_ST` 哑变量；样本稳健性检验 |
| 总股本变化 | 送股、转增、增发导致股本变动 | 用 CSMAR `Capchg` 表调整 |
| 关联交易金额 | 部分字段是元，部分是万元 | 在 codebook.md 中标注单位 |
| 现金流量表 | 早期上市公司未按统一标准披露 | 用 cashflow_synth 补充 |

### 12.2 微观调查数据

| 陷阱 | 说明 | 解决方案 |
|---|---|---|
| 基因值缺失 | CFPS 用 `-8`（不适用）、`-9`（缺失）、`-1`（不知道）等 | 严格按 Codebook 替换为 NaN |
| 跨年 ID 不匹配 | 家庭分家、个人死亡、迁移 | 用多键（ID+wave+家庭 ID）匹配 |
| 权重与抽样设计 | 微观调查有复杂抽样设计 | 用 `svyset` 或 `survey` 包 |
| 资产漏报 | 高净值家庭系统性低报资产 | Heckman 选择模型或 Tobit |
| 测量误差 | 自报收入、自报健康 | 用 instruments 或 MTMM 校正 |

### 12.3 面板数据

| 陷阱 | 说明 | 解决方案 |
|---|---|---|
| 个体消失 | 退出调查、死亡、迁移 | 用生存分析、IPW 校正 |
| 行政区划变更 | 撤县设区、市辖区调整 | 用民政部最新区划代码更新 |
| 数据可比性 | 不同年份指标定义变化 | 建 "指标版本映射表" |
| 跨库合并 | 不同抽样框、不同抽样设计 | 避免直接合并；做对比研究 |

### 12.4 时间序列数据

| 陷阱 | 说明 | 解决方案 |
|---|---|---|
| 数据修订 | GDP 三次修订、CPI 调整 | 用最新版本；在论文脚注说明 |
| 月度数据不规则 | 春节、节假日 | 加月度 dummy |
| 日度数据异常值 | 停牌、涨跌停 | 单独处理或剔除 |
| 数据延迟 | 公布时间不一致 | 区分"实际数据日期"和"公布日期" |

### 12.5 缺失值处理的中国特色

- **系统缺失**：政府统计中，落后地区数据缺失是常态，须用插值或邻近年份近似
- **调查无回应**：微观调查中无回应有选择性，必须用 IPW 或 Heckman
- **行政记录不匹配**：不同部委同一指标不一致（如 GDP vs 工信部工业增加值），须在论文说明选择
- **断点**：历史数据 1966-1976、1989-1990 部分指标缺失，须在实证中说明

## 14. 评估与质量门适配（与现有体系衔接）

### 14.1 数据治理分级（中国数据特色补充）

| 现有分级 | 中国语境特殊处理 |
|---|---|
| public | 国家统计局年鉴、CSMAR 部分公开字段、CNINFO 公告 |
| restricted | CSMAR/WIND/CHARLS/CFPS/CHFS/工业企业数据库（须学校 IP 或申请） |
| confidential | CID 微观、HS 8 位码海关总署原始数据、企业内部数据 |
| PII | 微观调查含身份证号、电话、地址、基因数据；必须脱敏或哈希 |

### 14.2 Method Gate 与 Draft Quality Gate 的中国适配

- **Method Gate** 新增"中国数据源检查"：数据源必须在 §0 索引内（CSMAR/WIND/CNINFO 等）才有"标准公开可得"标记；否则需 DAS。
- **Draft Quality Gate 维度⑦**（可复现性）新增：中国数据 DAS 必须明确是否通过学校订阅、是否提供申请流程、等待时间。
- **claim-integrity 审计**新增"中国数据描述准确性"：引用必须严格按数据源官方名称、URL、年份。

### 14.3 Citation-Temporal Integrity（中国数据专项）

- 中国数据的"样本期" vs "论文撰写期" 经常出现时间穿越问题（如 2023 年发布的数据用于 2020 年的实证）。
- 必须用 latest available vintage，并在 codebook.md 中记录数据获取日期。
- 引用时标注"访问日期 YYYY-MM-DD"。

## 15. 关键陷阱速查（Top 20）

1. **CSMAR 行业代码**：CSMAR 用证监会 2012，国家统计局用 GB/T 4754，**两者不能直接合并**
2. **CHARLS 抽样权重**：必须用对应年份的访谈权重，不用默认 weight
3. **CFPS 基因值缺失**：严格按 Codebook 处理 -8 / -9 / -1
4. **工业企业数据库销售额门槛**：2011 起 2000 万，之前 500 万，**时间序列必须调整**
5. **海关 HS 编码版本**：1992/1996/2002/2007/2012/2017 多版本，**必须用转换表**
6. **行政区划代码变更**：每年有撤县设区，**用民政部最新区划代码更新**
7. **GDP 三次修订**：必须用最终核实版本
8. **微观调查跨年 ID 匹配**：用 ID + wave + communityID 三层键
9. **数据出境安全评估**：100 万人以上个人信息处理者向境外提供前必须申报
10. **个人信息保护法**：含个人金融账户、医疗属敏感个人信息，须脱敏
11. **ST/\*ST 标记**：上市公司财务异常，须单独哑变量
12. **关联交易金额单位**：部分是元，部分是万元，须 codebook.md 标注
13. **专利申请号 vs 公开号**：研究时序用**申请日**
14. **数据延迟**：年度数据通常次年 3-6 月公布，须区分"实际日期"和"公布日期"
15. **WIND 字段命名**：很多字段是中文名，跨库合并时麻烦
16. **CHARLS 只覆盖 45 岁以上**：不能外推到全人口
17. **CHARLS 含死亡样本**：2020 wave 有退出问卷，处理时区分
18. **CHARLS 跨年 ID**：必须用 `rptype` 区分代答 vs 本人答
19. **高德/百度坐标系**：中国用 GCJ-02（火星坐标），与 WGS-84 偏差 100-700 米
20. **微观调查抽样设计**：必须用 svyset 或 survey 包指定
