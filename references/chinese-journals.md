### 0.2 按学位层级看选刊

| 学位 | 推荐投稿目标 | 备注 |
|---|---|---|
| **本科优秀毕业论文** | 通常**不要求发表**；发表可加综测分 | 学校认定即可 |
| **硕士学位论文** | 1-2 篇 CSSCI 期刊；部分院校要求至少 1 篇 | 北大光华、清华经管等要求更高（≥1 篇 C 刊） |
| **博士学位论文** | 3-5 篇 CSSCI；部分要求至少 1 篇校 A 类（顶刊级） | 不同学校 A 类/B 类目录不同 |
| **讲师晋升** | 1-2 篇 CSSCI | 部分院校要求核心期刊 |
| **副教授晋升** | 5-8 篇 CSSCI，其中 2-3 篇顶刊 | 部分要求代表作制（1 篇顶刊可代替若干 C 刊） |
| **教授晋升** | 顶刊 + 国际 SSCI 若干 | 各校差异极大 |

## 1. 中国期刊投稿通用流程与节奏

### 1.1 端到端时间线（典型时长）

```
论文定稿（含 tables/figures/refs） 约 2-4 周
  ↓
自查 + 查重 + 导师审阅       约 1-2 周
  ↓
选择目标期刊 1 主投 + 2 备    约 1 周
  ↓
按目标期刊格式重排 + 写 cover letter  约 1 周
  ↓
在线投稿（多数用 ScholarOne / 玛格泰克 / 自建系统）  当日
  ↓
初审（编辑内审，格式 / 选题匹配）   1-4 周
  ↓
外审（2-3 位匿名审稿人）         1.5-4 个月（顶刊 3-6 个月）
  ↓
退修（小修 / 大修 / 拒稿）       2-4 周（小修）/ 4-8 周（大修）
  ↓
复审 → 录稿通知 → 校样 → 见刊    2-6 个月
```

**典型总时长**：投稿到见刊，**中文顶刊 9-18 个月**，第二梯队 6-12 个月。

### 1.2 三种审稿结果

| 结果 | 含义 | 操作 |
|---|---|---|
| **直接录用 (Accept)** | 罕见（顶刊 <5%） | 庆祝；准备校样 |
| **小修 (Minor Revision)** | 30-40% 接受率（顶刊） | 1-2 周内逐条回应；不要偷懒不答 |
| **大修 (Major Revision)** | 30-40% | 1-2 个月内可能改 30-50% 内容；补充识别、稳健性、文献；附详细 response letter |
| **拒稿 (Reject, Desk)** | 选题不匹配 / 格式问题 / 初步判断 | **可改投**，不必绝望 |
| **拒稿 (Reject, After Review)** | 已外审但拒 | 认真读审稿意见；6-12 个月后可改投同刊（不同题目）；或改投他刊 |

### 1.3 关键纪律

1. **不"一稿多投"**：国内期刊明确禁止同时投两本；先投 A，A 拒后再投 B。审稿期内不要撤稿。
2. **不"伪造审稿人"**：国内审稿人圈子小，造假会被永久拉黑。
3. **认真写 cover letter**：编辑 5 分钟决定是否送审；cover letter 是第一道关。
4. **每轮回复都附详细的 response letter**：逐条回应，每条说明改了哪里、为什么这么改。
5. **保留所有原始数据 5-10 年**：中国期刊虽不像 AEA 强求 replication，但被举报数据造假时需要自证清白。

## 2. GB/T 7714-2015 引用规范详解

### 2.1 顺序编码制（国内主流）

国内 CSSCI 期刊绝大多数采用 GB/T 7714-2015 **顺序编码制**（[1], [2], [3]... 按出现顺序编码）。

#### 2.1.1 主要文献类型的格式

**期刊论文 [J]**：

```
[序号] 主要责任者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
```

示例：
```
[1] 周黎安, 沈倩. "文化"与经济发展[J]. 经济学(季刊), 2023, 23(2): 421-440.
[2] Chen Y, Liu Z, Zhang Y. Title of paper[J]. Journal Name, 2023, 45(3): 123-145.
```

**专著 [M]**：

```
[序号] 主要责任者. 书名[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

示例：
```
[3] 林毅夫. 解读中国经济[M]. 北京: 北京大学出版社, 2012.
[4] Acemoglu D, Robinson J. Why Nations Fail[M]. New York: Crown Business, 2012.
```

**学位论文 [D]**：

```
[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年份.
```

示例：
```
[5] 王明. 中国家庭金融脆弱性研究[D]. 北京: 北京大学, 2023.
```

**会议论文 [C]**：

```
[序号] 主要责任者. 题名[C]//会议录主要责任者. 会议录题名. 出版地: 出版者, 出版年: 引文页码.
```

**报纸文章 [N]**：

```
[序号] 主要责任者. 题名[N]. 报纸名, 出版日期(版次).
```

示例：
```
[6] 习近平. 加快建设科技强国[N]. 人民日报, 2022-06-25(01).
```

**电子文献 [EB/OL]**：

```
[序号] 主要责任者. 题名[文献类型标志/文献载体类型标志]. 出版地: 出版者, 出版年(更新或修改日期)[引用日期]. 获取和访问路径.
```

示例：
```
[7] 国家统计局. 中华人民共和国2023年国民经济和社会发展统计公报[EB/OL]. 2024-02-28[2024-03-15]. http://www.stats.gov.cn/sj/zxfb/202402/t20240228_1947915.html.
```

**数据集 [Z/DS]**（GB/T 7714-2015 增加的类型）：

```
[序号] 主要责任者. 数据集名[Z]. 出版地: 数据提供方, 年份.
```

示例：
```
[8] CSMAR 中国股票市场研究数据库[Z]. 深圳: 深圳希施玛数据科技有限公司, 2023.
```

**工作论文 [R]**：

```
[序号] 主要责任者. 题名[R]. 出版地: 单位, 年份.
```

#### 2.1.2 责任者（作者）写法

- **中文作者**：姓在前名在后，全名写出（如"周黎安"）；3 人以下全列，4 人以上列前 3 人后加"等"或"et al"。
- **英文作者**：姓在前名缩写在后（如"Chen Y"），姓名之间空 1 格；3 人以下全列，4 人以上列前 3 人后加"et al"。
- **机构作者**：用机构全称（如"World Bank"），不用缩写。

#### 2.1.3 特殊处理

- **英文期刊**：刊名可用缩写（按 ISO 4 标准），但全称也可。国内一般写全称。
- **DOI**：可加在期刊论文后，格式 `DOI: 10.xxxx/xxxxx`。
- **arXiv / 工作论文**：当作工作论文 [R] 处理，注明 arXiv 编号。
- **中文网页**：作者若是机构，写机构名；若是个人，写姓名。

### 2.2 著者-出版年制（Harvard Style）

少数国内期刊（如《经济研究》部分投稿可选用）允许 Harvard Style（作者, 年份），但**国内主流仍是顺序编码制**。如果不确定，**默认用顺序编码制**。

示例（Harvard）：
```
周黎安 and 沈倩. 2023. "文化"与经济发展. 经济学(季刊) 23(2): 421-440.
Chen Y, Liu Z, and Zhang Y. 2023. Title of paper. Journal Name 45(3): 123-145.
```

### 2.3 GB/T 7714-2015 与 APA / Chicago 的关键差异

| 项目 | GB/T 7714 (中文主流) | APA 7 | Chicago |
|---|---|---|---|
| 引用方式 | 顺序编码 [1] | 作者-年份 (Smith, 2020) | 作者-年份或脚注 |
| 作者姓名顺序 | 姓全名 | 姓, 名首字母 | 姓, 名 |
| 标题大小写 | 句首大写 | 句首大写 | 标题大小写 |
| 期刊名斜体 | 否 | 是 | 是 |
| 卷(期) | 25(3) | 25(3) | 25, no. 3 |
| 期刊缩写 | 不用 | 用 | 用 |
| 期刊论文页码 | 起止 | 起止 | 起止 |
| 出版地：出版者 | 北京: 北大出版社 | City: Publisher | City: Publisher |
| DOI | 可选 | 必填 | 可选 |

**国内期刊投稿时**：按目标期刊最新《投稿须知》调整；不确定时用 GB/T 7714 顺序编码制。

### 2.4 Zotero 中 GB/T 7714-2015 配置

- 在 Zotero Style Repository（https://www.zotero.org/styles）搜索 "GB/T 7714" 或 "中国国家标准"
- 推荐样式：
  - **`chinese-gb7714-2015-numeric.csl`**：顺序编码制（最常用）
  - **`chinese-gb7714-2005-numeric.csl`**：旧版 2005（部分老刊仍在用）
  - **`chinese-gb7714-2015-author-date.csl`**：著者-出版年制
- 配置步骤：Zotero → 设置 → 引用 → 获取更多样式 → 搜索上述样式 → 安装 → 选择使用

## 3. 五大顶刊投稿规范（详细）

### 3.1 《经济研究》

- **主办**：中国社会科学院经济研究所
- **ISSN/CN**：ISSN 0577-9154；CN 11-1081/F
- **学术地位**：国内经济学公认**第一刊**（CSSCI 来源刊、院学位分委会常列入顶刊 A 类）
- **2024 年影响因子**（CSSCI 期刊引证报告）：约 15-18
- **官网**：http://www.erj.cn/
- **投稿系统**：在线投稿（玛格泰克 Magtech 系统）
- **审稿周期**：3-6 个月；审稿严格，拒稿率约 85-90%
- **选题偏好**：
  - **重大现实问题**：中国宏观经济、体制改革、收入分配、产业升级
  - **理论创新**：本土化经济学理论（不是简单应用国外模型）
  - **前沿方法**：双重差分、断点回归、合成控制等现代计量方法
  - **重视"中国故事"**：能用中国数据讲清经济规律
- **字数要求**：通常 **1.5-2.5 万字**（含图表、参考文献），正文中英文部分不强制
- **格式要求**：
  - 中文摘要 **200-300 字**，关键词 3-5 个
  - **JEL 分类号**：（可选，但建议提供 3-5 个）
  - 参考文献：**GB/T 7714-2015 顺序编码制**
  - **匿名审稿**：必须，正文中不得出现作者信息（封面、致谢）
  - **查重率**：通过初审时系统查重，重复率一般要求 < 10%（严格）
- **方法要求**：
  - 必须使用**现代实证方法**（DiD/IV/RDD/SC/DML 等）
  - 识别策略必须**清晰**：平行趋势检验、第一阶段 F、稳健性等
  - 必须有**机制分析**（中介或调节）
- **投稿 cover letter 模板**：

```
尊敬的《经济研究》编辑部：

我们谨向贵刊投稿题为"《论文题目》"的稿件。该论文研究了《一句话研究问题》，
采用《XX 方法》对《数据来源》进行分析。研究发现，《主要结论 1》《主要结论 2》
《主要结论 3》。本文的主要贡献在于：第一，理论贡献；第二，方法贡献；第三，
政策含义。

本文未曾在任何期刊发表，亦未在其他期刊投稿。全体作者同意投稿，并确认无利益冲突。

推荐审稿人（可选）：
1. 张三 教授 XX大学XX学院 研究方向：XXX 邮箱：xxx@xx.edu
2. 李四 副教授 XX大学XX系 研究方向：XXX 邮箱：xxx@xx.edu

建议回避的审稿人（可选）：王五 教授（与作者存在合作关系）

此致
敬礼

第一作者姓名
20XX 年 X 月 X 日
```

- **投稿后预期**：
  - 初审：1-4 周（编辑内审）
  - 外审：3-6 个月（2-3 位审稿人，多数顶刊用 3 位）
  - 退修（如果是小修/大修）：2-4 周（必须逐条回复 + 修改稿标注）
  - 录稿到见刊：3-6 个月
- **重要提醒**：
  - **必须有"研究意义"段落**：明确说出对经济学理论/政策/方法论的贡献
  - **必须有"中国故事"**：避免全盘套用国外模型而不解释中国特色
  - **审稿人极严**：退修概率高，3-5 轮修改是常态
  - **政治敏感话题**：与改革开放、所有制、宏观调控等相关的部分要政治正确

### 3.2 《管理世界》

- **主办**：国务院发展研究中心
- **ISSN/CN**：ISSN 1002-5502；CN 11-1235/F
- **学术地位**：管理学/经济学交叉**第一刊**（CSSCI 来源刊）
- **2024 年影响因子**：约 12-15
- **官网**：http://www.mwm.net.cn/
- **投稿系统**：在线投稿
- **审稿周期**：3-6 个月；拒稿率约 80-85%
- **选题偏好**：
  - **管理实践重大问题**：企业战略、组织行为、人力资源、营销
  - **宏观管理**：政府治理、产业发展政策、宏观调控
  - **跨学科**：经济学 + 管理学 + 政策研究
  - **重视"政策含义"**：对管理实践的指导意义
- **字数要求**：**1.5-2.5 万字**
- **格式要求**：
  - 中文摘要 200-300 字
  - 关键词 3-5 个
  - **必须 JEL 分类号**
  - 参考文献 GB/T 7714-2015
  - 匿名审稿严格
  - 查重率 < 10%
- **与《经济研究》的差异**：
  - 更偏向管理学 + 政策导向
  - 接受案例研究、行业研究、政策研究
  - 实证研究方法标准与《经济研究》相当
- **特殊偏好**：
  - **国有/民营企业管理实践**（与《管理世界》的"中国企业管理"特色契合）
  - **产业政策评估**
  - **数字化转型与企业行为**

### 3.3 《经济学（季刊）》

- **主办**：北京大学中国经济研究中心（现国家发展研究院）
- **ISSN/CN**：ISSN 1005-3836；CN 11-6010/F
- **学术地位**：北大经济学的旗舰刊物；**经济理论严谨**
- **2024 年影响因子**：约 10-13
- **官网**：http://nsd.pku.edu.cn/journal.html（部分通过北大网站投稿）
- **投稿系统**：在线投稿（部分作者邮件提交）
- **审稿周期**：3-6 个月；拒稿率约 80-85%
- **选题偏好**：
  - **理论方法创新**：偏向经济学方法论上的推进
  - **中国问题**：中国改革、增长、转型
  - **接受较长论文**：可发表工作论文长度的研究
  - **重视"识别策略"**：对内生性问题处理要求高
- **字数要求**：**2-3 万字**（含图表、参考文献，可长一些）
- **格式要求**：
  - 中文摘要 200-300 字
  - 关键词 3-5 个
  - JEL 分类号
  - GB/T 7714-2015
  - 匿名审稿严格

## 5. 投稿策略与生态

### 5.1 选刊决策树

```
Step 1: 论文质量定位
  ├─ 顶刊级（方法严谨 + 重大贡献）  → 投 5 大顶刊
  ├─ 高水平（方法过关 + 较新贡献）  → 投第二梯队 B 类
  └─ 一般（方法可用 + 边际贡献）    → 投 C 类或应用类

Step 2: 选题匹配度
  ├─ 完全匹配目标期刊偏好  → 投主刊
  └─ 部分匹配                → 调整框架重写（突出匹配角度）

Step 3: 1 主投 + 2 备
  ├─ 主投：选题最匹配的顶刊
  ├─ 备 1：同级别、方法导向更匹配的刊物
  └─ 备 2：低一档但接受度高（如数量经济、改革）
```

### 5.2 cover letter 通用要素

1. **论文题目**：完整标题（中英文）
2. **研究意义**：用 1-2 句话讲清楚对经济学/管理学的贡献
3. **主要发现**：3 个 bullet points（最重要的 3 个结论）
4. **方法创新**：用了什么方法、与已有研究的方法差异
5. **数据来源**：明确数据是否受限、是否公开可得
6. **原创性声明**：未投他刊、未发表、所有作者同意
7. **利益冲突**：如有，声明
8. **推荐审稿人**（可选）：3-5 位国内同行，附邮箱和单位
9. **建议回避审稿人**（可选）：列明利益冲突的同行

### 5.3 拒稿后的应对

| 拒稿类型 | 信号 | 应对策略 |
|---|---|---|
| **Desk Reject**（编辑拒稿） | "选题与本刊方向不符" | 改投他刊；不浪费修改时间 |
| **Review Reject**（外审后拒稿） | "识别假设不成立" / "结论不稳健" | 认真读意见；3 个月内不得重投同刊；6-12 个月后可改投 |
| **Major Revision 后拒稿** | 修改不到位 | 改投他刊；下次彻底重做 |

### 5.4 修改后改投（同主题）

**不要"一稿多投"**，但允许"撤稿后改投"：
- 撤稿时机：Major Revision 拒稿后立即撤稿
- 改投时机：撤稿后即可投他刊（不必等 6 个月）
- 改投时**修改稿件**：根据前刊意见优化；写新的 cover letter 说明与前刊的差异

### 5.5 与导师的合作模式

- **本科**：导师亲自写或全程指导
- **硕士**：导师修改大纲，学生写初稿
- **博士**：导师给方向，学生独立完成
- **青年讲师**：与导师合作，第一作者通常是学生/讲师

### 5.6 "中国故事" 写法要点

国内顶刊非常重视"中国故事"：
- **避免**：直接套用国外模型而不解释中国特色
- **应该**：
  1. 用中国数据
  2. 讲中国经济现象
  3. 解释中国制度背景
  4. 与中国政策对话（"对 XX 政策的启示"）
  5. 贡献本土化理论（不是简单应用西方模型）

### 5.7 政治敏感话题的红线

**绝对禁忌**：
- 否定党的领导
- 质疑社会主义制度
- 涉及少数民族、台港、新疆、西藏的负面表述
- 否定改革开放

**需谨慎处理**：
- 国有经济效率（要平衡）
- 政策失败案例（要分析原因，不是简单批评）
- 国际比较（避免不必要对比）

## 6. 学位论文场景（按学位层级）

### 6.1 本科毕业论文（8000-15000 字）

**结构**（典型）：
- 封面、原创性声明、目录
- 中文摘要 + 关键词（200-300 字）
- 英文摘要 + 关键词
- **第一章 绪论**（1500-2500 字）：选题背景、意义、研究方法、创新点
- **第二章 文献综述**（1500-2500 字）
- **第三章 理论分析与研究假设**（1500-2500 字）
- **第四章 研究设计**（1500-2500 字）
- **第五章 实证结果**（2000-3000 字）
- **第六章 结论与讨论**（1000-1500 字）
- 参考文献（10-30 篇）
- 致谢

**评审要求**：
- 选题有意义
- 方法基本正确
- 结论清晰
- 格式规范
- 查重率一般 < 25-30%（各校不同）

### 6.2 硕士学位论文（3-5 万字）

**结构**（典型）：
- 封面、原创性声明、目录、图目录、表目录
- 中文摘要（500-800 字）+ 关键词
- 英文摘要 + 关键词
- **第一章 绪论**（4000-6000 字）：选题背景、意义、研究方法、创新点
- **第二章 文献综述**（5000-8000 字）
- **第三章 理论分析**（4000-6000 字）
- **第四章 研究设计**（3000-5000 字）
- **第五章 实证结果**（8000-12000 字）
- **第六章 进一步分析**（5000-8000 字）：机制、异质性
- **第七章 结论与政策建议**（2000-3000 字）
- 参考文献（50-100 篇）
- 附录（详细推导、稳健性表、调研问卷等）
- 致谢

**评审要求**：
- 选题有理论与现实意义
- 方法现代、严谨
- 创新点明确（1-3 个）
- 有**独立的实证贡献**（不是综述）
- 查重率 < 10-15%
- 盲审（隐藏作者信息）
- 答辩 PPT 制作（10-15 分钟讲清楚）

### 6.3 博士学位论文（8-15 万字）

**结构**（典型）：
- 封面、原创性声明、目录、图目录、表目录
- 中文摘要（800-1500 字）+ 关键词
- 英文摘要 + 关键词
- **第一章 绪论**（8000-12000 字）：包括研究背景、问题提出、研究意义、研究框架、研究方法、创新点
- **第二章 文献综述与理论基础**（10000-15000 字）
- **第三章 理论模型**（8000-12000 字）
- **第四章 研究设计**（5000-8000 字）
- **第五章 实证结果**（15000-25000 字）
- **第六章 进一步分析**（10000-15000 字）
- **第七章 政策建议**（3000-5000 字）
- **第八章 研究结论与展望**（3000-5000 字）
- 参考文献（100-300 篇）
- 附录（详细推导、稳健性表、原始数据描述等）
- 致谢、博士在读期间科研成果

**评审要求**：
- 选题有**重要理论与现实意义**
- 方法现代、严谨，**有方法论贡献**
- 创新点明确（通常要求 **3 个创新点**，每个要明确）
- 有**系统性的实证贡献**（多个章节、多篇发表的支撑）
- 查重率 < 5-10%（各校不同，但都比硕士严）
- 盲审（5 位专家）
- 答辩：预答辩 → 修改 → 正式答辩（30-45 分钟陈述 + 30 分钟问答）
- 答辩委员会 5-7 人（其中校外专家 ≥2 人）

### 6.4 学位论文的"创新点"写法

国内学位论文对**创新点**要求极高。常见创新点类型：

| 类型 | 写法 | 示例 |
|---|---|---|
| **理论创新** | 提出新理论模型或新概念 | "本文在 XX 理论基础上引入 XX 维度，构建了 XX 模型" |
| **方法创新** | 改进现有方法 | "本文将 XX 方法与 XX 方法结合，提出 XX 估计量" |
| **数据创新** | 使用新数据 | "本文使用 XX 数据库 20XX-20XX 年 XX 万样本" |
| **应用创新** | 把已有方法/理论应用到新问题 | "本文首次将 XX 模型应用到 XX 领域" |

### 6.5 答辩 PPT 通用结构

1. **选题背景与意义**（2-3 张）：为什么重要、研究问题
2. **文献综述**（1-2 张）：研究缺口、本文定位
3. **理论框架与研究假设**（2-3 张）：模型、假设
4. **研究设计**（1-2 张）：数据、方法
5. **实证结果**（5-10 张）：主要发现（按章节）
6. **稳健性**（2-3 张）：各种稳健性检验
7. **机制与异质性**（2-3 张）：机制分析
8. **结论与贡献**（1-2 张）：主要贡献、政策建议
9. **研究局限与展望**（1 张）：诚实交代
10. **致谢**（1 张）

## 9. 关键陷阱速查（Top 20）

1. **混淆"字数"含义**：中文期刊字数通常指**正文字数**（不含参考文献），不是全文总字数
2. **查重率过红线**：每本期刊红线不同，顶刊多 < 10%；提前查
3. **作者信息泄露**：致谢、基金号、英文摘要单位都可能有作者信息；匿名审稿必须全文无痕
4. **JEL 分类号遗漏**：顶刊必填
5. **关键词不在主题**：关键词决定检索命中率，要和内容直接相关
6. **英文摘要比中文摘要短**：很多中文期刊要求英文摘要略短（150-200 字）
7. **DOI 缺失**：新文献务必补充 DOI
8. **网页引用不规范**：政府公告、统计公报必须按 [EB/OL] 格式
9. **作者英文名错乱**：拼音写错、姓名顺序颠倒
10. **基金号遗漏**：必须有资助来源（基金委、社科基金、教育部等）
11. **作者顺序争议**：投稿前所有作者签字同意
12. **Cover letter 写得太空泛**：必须明确说出研究贡献
13. **推荐审稿人是熟人**：必须客观列同领域专家
14. **图分辨率不够**：300+ dpi 是底线
15. **表格不规范**：中文期刊表格通常**全边框**（不用三线表）
16. **LaTeX 模板用错**：不同期刊的 .cls 不同
17. **跨页表格没处理**：表格必须在同一页或显式说明跨页
18. **图表编号不规范**：中文期刊通常**图 1、表 1** 顺序独立编号（不连续）
19. **数学公式没转 Word 公式**：用 Word 内置公式编辑器重排
20. **提交后没确认状态**：投稿系统状态变更是异步的，要定期登录查看

## 11. 与现有体系衔接

### 11.1 与 paper-writer 子 skill 的协作

- **Stage 5 写作初稿**：调用 `67/paper-writer`，按本文件 §6 选择对应模板
- 中文期刊 vs 英文期刊，**必须**在 paper-writer 调用前明确目标期刊
- paper-writer 输出后，按本文件 §3-4 调整格式

### 11.2 与 peer-review-and-submission 的协作

- **Stage 8 模拟评审**：调用 `67/referee-report` 等；**中文期刊评审人风格与英文不同**——更注重"研究意义"和"政策含义"，所以 response letter 中要重点突出这两点
- **Stage 9 选刊与投稿**：按本文件 §0、§3-4 选刊，按 §7 准备材料

### 11.3 与 quality-rubric 的扩展

**初稿质量门维度 ⑤ 写作与结构**：
- 中文期刊补充标准：
  - 摘要完整性（200-300 字包含目的/方法/结果/意义）
  - "研究意义"段落必须显式
  - 政策含义段落必须显式（顶刊）
  - 章节命名符合中文学术规范（不用 IMRaD 直译）

**初稿质量门维度 ⑥ 引用真实性**：
- 中文期刊补充：GB/T 7714-2015 格式合规
- 中文文献覆盖度（不能全是英文文献，至少有 5-10 篇 CSSCI 顶刊引用）

### 11.4 与 citation-and-temporal-integrity 的衔接

- **引用存在性核验**：对国内期刊同样适用——中文期刊存在"假引用"、"张冠李戴"问题
- **时序完整性**：中文期刊对"最新文献"要求略松，但**至少应有 2023-2025 年的最新文献**
- **GB/T 7714 字段映射**：在 citation-and-temporal-integrity 中加入 "GB/T 7714-2015 顺序编码制" 字段定义

### 11.5 与 integrity-and-claim-audit 的衔接

- **claim 忠实度审计**：中文期刊对 claim 的"政策含义"层级有特殊要求
- **forbidden wording**：中文期刊要避免：
  - "本文证明了..."（过强，应改为"本文发现/揭示/支持"）
  - "填补了 XX 领域空白"（除非真的有重大创新）
  - "首次发现 XX"（除非真的是首次）
  - 模糊量化的承诺（"有效解决"、"完美解释"）

## 13. 学位论文 vs 期刊投稿：关键差异

| 项目 | 期刊投稿 | 学位论文 |
|---|---|---|
| 创新点要求 | 通常 1-2 个 | 必须 3 个（博士） |
| 字数 | 1-3 万 | 8-15 万（博士） |
| 摘要字数 | 200-300 | 800-1500（博士） |
| 评审方式 | 匿名外审 | 校内 + 校外盲审 |
| 创新点声明 | 不强制 | **必须显式列出** |
| 政策建议 | 顶刊必要 | 必要（博士） |
| 查重率 | < 10% | < 5-10% |
| 答辩 | 无 | **有**（10-45 分钟） |
| 出版要求 | 无 | **多数博士要求 1-2 篇 CSSCI 发表** |
| 装订 | 电子版即可 | 精装纸质版若干本 |
| 原创性声明 | 一般 | **必须**手写签名 |
