## 6. 边界分析（未观测混淆）

### E-value (VanderWeele \& Ding 2017)

基于 OLS+X 点估计 $\beta=0.186$（$RR=1.20$）：
- E-value = **1.70**（点估计）
- E-value = **1.82**（95\% CI 上界）

含义：需一个 RR=1.70 的未观测混淆才能完全推翻结论。

### Oster (2019) 边界

| $\delta$ | 调整后 $\beta$ | 与真值 0.18 的关系 |
|---|---|---|
| 1.0 | **0.113** | 仍显著 > 0 |
| 1.5 | -0.018 | 接近 0 |
| 2.0 | -0.149 | 完全推翻 |

即使未观测因素与已观测因素同等重要（$\delta=1$），调整后系数仍为正（0.113）。

## 9. 注意事项

1. **数据为合成**：DGP 真值已知，仅用于方法演示；真实研究请使用 [CFPS](https://www.isss.pku.edu.cn/cfps/) 官方数据。
2. **文献综述省略**：根据用户指示，未联网检索文献，论文采用"方法示例"框架而非完整文献综述。
3. **目标期刊《经济研究》**：本文格式按中文学术期刊规范编写（摘要、关键词、JEL、引言→数据→方法→结果→结论），但篇幅与深度仅作"初稿"用，正式投稿需大幅扩展。
4. **2SLS 显著性受限**：受 N=2000×2 限制，IV 估计点估计方向正确但 SE 偏大；真实 CFPS 数据 N 远大于此，2SLS 精度会显著提升。
5. **5 张图全部用中文标签**（使用 macOS Heiti SC / Songti SC），若迁移至其他系统可能需要替换字体。
